# BIT 2118 Scientific Computing Group Work

This repository contains the practical tasks for BIT 2118. Each task has a code folder and a documentation folder.

## Task 2
- Code: `Task_02_NumPy_Arrays/code/Task_02_numpy_arrays.py`
- Documentation: `Task_02_NumPy_Arrays/documentation/Task_02_Documentation.md`

## Setup
Install the required libraries once from the project root:

```powershell
py -m pip install numpy scipy matplotlib
```

Run Task 2:

```powershell
py Task_02_NumPy_Arrays\code\Task_02_numpy_arrays.py
```
